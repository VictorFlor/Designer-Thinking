## 🧠 Metodologia: O Uso dos Prompts

Um dos maiores diferenciais deste projeto foi o processo de criação. Em vez do desenvolvimento tradicional, utilizei o Gemini como "Pair Programmer". 

Alguns exemplos de fluxos de prompts utilizados:
1. *Prompt de Estruturação:* "Atue como um Web Designer especialista em UI/UX. Crie a estrutura de seções para uma apresentação sobre..."
2. *Prompt de Estilização:* "Gere um código CSS moderno, utilizando Flexbox e uma paleta de cores baseada em tons de..."
3. *Prompt de Conteúdo:* "Reescreva este parágrafo de forma mais persuasiva para prender a atenção do leitor..."
